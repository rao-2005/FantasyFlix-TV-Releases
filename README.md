# FantasyFlix TV — Releases

Release channel for the **FantasyFlix Android TV / Google TV** app.

- Download the latest `FantasyFlix-TV-<version>-universal.apk` from the [Releases](../../releases) page and sideload it.
- After the first install, updates arrive in-app: **Settings → Check for updates**. The app downloads the new APK and asks you to confirm the install once.
- First install only: allow "Install unknown apps" for FantasyFlix when Android asks.
